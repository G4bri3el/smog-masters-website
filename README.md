# Smog Masters Smog Check

Static corporate landing page for Smog Masters Smog Check in Gardena, California.

## Stack

- Astro
- TypeScript
- Tailwind CSS
- Static HTML output
- Cloudflare Pages

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`

## Business Data

Business information is centralized in `src/config/site.ts`. Update verified business details there before changing page components.

Optional Google Analytics support is prepared through `PUBLIC_GA_ID`.
